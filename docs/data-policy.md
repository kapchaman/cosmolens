# Scientific Data Policy

CosmoLens should never make astronomy feel more certain than it is.

## Rules

1. Every non-trivial object fact must have at least one source.
2. Values must be labeled as measured, estimated, modeled, theoretical, or contextual.
3. Unknown values should stay unknown instead of being filled for symmetry.
4. AI responses must distinguish observation from interpretation.
5. Hypothetical scenarios must be visibly labeled as hypothetical.
6. External API failures must produce fallback states, not fabricated astronomy data.

## Source Preference

Prefer NASA, ESA, ESO, JPL, SIMBAD, NED, mission pages, and peer-reviewed literature. Popular articles can support UX copy but should not be the only source for scientific metadata.
